# ⏱️ Jetpack Compose Timer Clock

This project is a simple yet practical Android application built using **Kotlin** and **Jetpack Compose**. It demonstrates how to build a responsive UI that displays the **current time, date, and weekday**, while also offering a **start/stop timer feature**. The app leverages **Material3 components** for a modern look and uses **coroutines (`LaunchedEffect`)** to handle real-time updates efficiently.

---

## 📖 Overview
The Timer Clock app is designed to showcase:
- Real-time clock updates every second.
- Date formatting with weekday names (e.g., *Thursday, 13 August 2026*).
- A clean, card-based UI layout with centered content.
- Interactive buttons to **start** and **stop** the timer, reflecting the current status.
- Logging for debugging, showing when the timer starts, stops, and updates.

---

## ✨ Features
- **Live Clock**: Updates every second using Kotlin coroutines.  
- **Date Display**: Shows the full date with weekday and month name.  
- **Start/Stop Timer**: Buttons to control the timer state.  
- **Status Indicator**: Displays whether the timer is running or stopped.  
- **Material3 UI**: Modern design with `Card`, `Button`, and `Text` components.  
- **Logging**: Debug logs for time updates and timer state changes.  

---

## 🛠️ Tech Stack
- **Language**: Kotlin  
- **UI Framework**: Jetpack Compose  
- **Design System**: Material3  
- **Concurrency**: Coroutines (`LaunchedEffect`)  
- **Android SDK**: Requires Android 8.0 (API 26) or higher
